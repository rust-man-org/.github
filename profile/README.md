# Rustman

**Building fast, native, open-source developer tools in Rust.**

We build tools that respect your machine, your privacy, and your time.

Our flagship project, **Rustman**, is a free and open-source API client built entirely in Rust. No Electron, no WebView, no account, and no telemetry. Just a native application that gets the job done.

## Our Projects

### [Rustman](https://github.com/rust-man-org/rustman)

A lightweight, native API client built with Rust and [iced](https://github.com/iced-rs/iced).

- Native desktop experience with no embedded browser
- HTTP requests, WebSockets, and authentication
- Collections, environments, and request history
- Git integration for version-controlled collections
- Custom scripting engine written in Rust
- Free and open source, with no accounts or telemetry

## Our Philosophy

- **Native first.** Build software that uses system resources thoughtfully.
- **Privacy by default.** Your data belongs to you.
- **Open source.** Build in public and make our work accessible to everyone.
- **Performance matters.** Fast software should not require heavyweight applications.
- **Community driven.** Great tools get better when people build them together.
